When capturing the production screenshot/GIF for `README.md`, capture:

2. **Themes:** Both Light and Dark theme captures (or a side-by-side / toggle GIF).
3. **Featured Document Sample:** Open a document containing:
   - **Persian / Arabic RTL mixed with English:** Demonstrating per-block auto-detection (`dir="auto"`) and proper alignment.

   - **LaTeX Math Formula:** Mathematical expressions rendered with KaTeX (e.g. $\int_0^\infty e^{-x} dx = 1$).

   - **UI Chrome:** Showing the active tab bar, Table of Contents sidebar, and clean title bar.
