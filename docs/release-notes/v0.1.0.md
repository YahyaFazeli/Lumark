## Highlights

- **Fast, Offline Markdown Reader:** Clean, distraction-free desktop reading for CommonMark and GitHub Flavored Markdown (tables, task lists, strikethrough, autolinks) with 100% offline local rendering and zero telemetry.
- **Rich Technical Content:** Syntax-highlighted code blocks with Shiki, offline LaTeX math formula rendering with KaTeX (bundled WOFF2 fonts), and Mermaid diagram visualization.
- **First-Class Bidirectional (RTL/LTR) Support:** Automatic per-block direction detection (`dir="auto"`) for Persian, Arabic, and Hebrew, with scoped CSS direction precedence and non-prose LTR isolation for code, math, and diagrams.
- **Deep Desktop Integration:** Local single-instance window coordinator, `.md`/`.markdown` file associations, drag-and-drop file opening, CLI argument forwarding, and multi-document tabs with session restoration.
- **Reading Experience:** In-document text search with match cycling, interactive Table of Contents (TOC) sidebar, Light/Dark/System themes, zoom controls (50%–300%), and debounced live file watcher.

| Platform | Architecture | Package Format | Filename | Description |

## Checksum Verification

Download `SHA256SUMS.txt` into the same directory as your downloaded package and verify its integrity:

- **Linux:**
  ```bash
  sha256sum -c SHA256SUMS.txt --ignore-missing
  ```

- **macOS:**
  ```bash
  shasum -a 256 <filename>
  ```
  *(compare the resulting hash against the matching line in `SHA256SUMS.txt`)*

- **Windows (PowerShell):**
  ```powershell
  Get-FileHash <filename> -Algorithm SHA256
  ```
  *(compare the `Hash` value against the matching line in `SHA256SUMS.txt`)*

## Unsigned Builds Notice

Lumark is an independent open-source project and release binaries are not digitally signed with commercial Microsoft Authenticode or Apple Developer ID certificates yet. Code signing and notarization will be introduced in an upcoming release.

Depending on your operating system, you may see security prompts during installation:

- **Windows SmartScreen:**
  - Windows Defender SmartScreen may display: *"Windows protected your PC / Microsoft Defender SmartScreen prevented an unrecognized app from starting"*.
  - Click **More info**, then click **Run anyway** to proceed with installation.

- **macOS Gatekeeper:**
  - On first launch, macOS may report that Lumark cannot be opened because the developer cannot be verified.
  - In Finder, open the `/Applications` folder, **right-click** (or Control-click) `Lumark.app`, select **Open**, and click **Open** in the confirmation dialog.
  - If macOS shows *"'Lumark' is damaged and can’t be opened. You should move it to the Trash"*, clear the quarantine attribute via Terminal:
    ```bash
    xattr -dr com.apple.quarantine /Applications/Lumark.app
    ```

## Linux Notes

- **Ubuntu 24.04+ (FUSE 2 Requirement for AppImage):**
  Ubuntu 24.04 and newer distributions default to FUSE 3 without backward-compatible FUSE 2 libraries. If the AppImage does not launch, install the FUSE 2 compatibility library:
  ```bash
  sudo apt install libfuse2t64
  ```
  *(On Ubuntu 22.04 or older, use `sudo apt install libfuse2`)*

- **Runtime Dependencies (.deb & .rpm):**
  Debian packages (`.deb`) support both modern GTK4 / WebKitGTK 6.0 and GTK3 / WebKit2GTK 4.1 runtime stacks. The published v0.1.0 RPM package was built with static dependencies for Fedora (GTK4 and WebKitGTK 6.0); broader dual-stack dependency compatibility (e.g. for RHEL / Rocky Linux) ships in v0.1.1:
  ```bash
  # Debian / Ubuntu / Linux Mint
  sudo apt install ./lumark_0.1.0_linux_amd64.deb

  # Fedora
  sudo dnf install ./lumark_0.1.0_linux_amd64.rpm
  ```
